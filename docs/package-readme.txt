MusicFloat

使用方法：
1. 将 ZIP 文件完整解压到一个文件夹。
2. 运行 MusicFloat.exe，本发布包已内置 .NET 运行时，无需另外安装。
3. 升级前请先退出旧版本，原有设置和快捷键会保留。

适用于 Windows 10 1809 及以上版本 / Windows 11（x64）。
如果开启代理后网易云封面显示异常，可尝试关闭代理后重试。

---

How to use:
1. Extract the entire ZIP file to a folder.
2. Run MusicFloat.exe. This package includes the .NET runtime; no separate installation is needed.
3. Exit the old version before upgrading. Your settings and shortcuts are retained.

For Windows 10 version 1809 or later / Windows 11 (x64).
If CloudMusic artwork fails to appear with a proxy enabled, try again with the proxy disabled.
