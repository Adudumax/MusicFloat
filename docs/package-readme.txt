MusicFloat

使用方法：
1. 将 ZIP 文件完整解压到一个文件夹。
2. 如果尚未安装 .NET 8 Desktop Runtime x64，请先安装它。
3. 运行 MusicFloat.exe。

微软 .NET 8 运行库下载：
https://dotnet.microsoft.com/download/dotnet/8.0/runtime

请在微软页面中选择：
.NET Desktop Runtime 8.x - Windows x64
