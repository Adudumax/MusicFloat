## 更新内容

- 修复固定音乐源后，操作网页视频可能误弹悬浮窗的问题。
- 修复切歌后，“抓取源”列表中来源名称后面的歌名不更新，以及更新歌名时已固定的来源选择丢失的问题。
- 修复同专辑歌曲共用封面时，切换上一首或下一首不弹出悬浮窗，且手动显示当前歌曲时仍显示最初播放歌曲的问题。
- 修复部分手柄快捷键失效的问题，改善使用稳定性。

## 当前限制

- 需要安装 .NET 8 Desktop Runtime（x64），使用方式与之前版本一致。
- 如果开启代理后网易云封面显示异常，可尝试关闭代理后重试。

## What's new

- Fixed unwanted overlays when controlling browser videos with a music source pinned.
- Fixed the song title after the source name in the capture-source list not updating after a track change, and the pinned-source selection being lost when that title updated.
- Fixed missing previous/next-track popups when songs from the same album shared artwork, and manually showing the current track still displaying the first played song.
- Fixed unresponsive shortcuts on some gamepads and improved stability.

## Current limitations

- Requires the .NET 8 Desktop Runtime (x64), as in previous releases.
- If CloudMusic artwork fails to appear with a proxy enabled, try again with the proxy disabled.
